## 1 引言

### 1.1 编写目的

定义"全国碳排放数据生成服务"的功能、数据、接口与验收要求，作为该功能设计、开发与测试依据。本功能是对主 SRS 中 M2 数据管理模块（FR-05 模拟数据生成器）的**升级替换**。

### 1.2 范围

- **范围内**：真实行政区划（大陆 31 省级 + 地级行政单位）、各省差异化月度活动数据生成、每月自动增量、全国地图热力大屏、旧演示数据切换清理。
- **范围外**：区县级数据、港澳台数据、真实企业台账数据接入、硬件采集。

### 1.3 术语

| 术语 | 说明 |
|---|---|
| 电网区域 | 生态环境部分区电网排放因子口径：华北/东北/华东/华中/西北/南方六个区域 |
| 供暖省份 | 位于秦岭—淮河线以北、实行集中供暖的省份（约 15 个） |
| 已过完的最新月份 | 以系统当前日期为准的上一个完整自然月（如 2026-09-14 → 2026-08） |
| 省级参数 | 每省一组经济能源特征参数（GDP、二产占比、煤炭占比、能耗强度、电网、供暖） |

## 2 功能需求

> 编号 CG-XX；优先级：高（必须）/ 中（重要）。

### 2.1 真实行政区划

| 编号 | 需求 | 优先级 |
|---|---|---|
| CG-01 | 内置大陆 31 个省级行政区 + 全部地级行政单位（地级市/地区/自治州/盟，约 333 个）及直辖市辖区（约 80 个），**名称与行政区划代码符合 GB/T 2260**（实现时基于民政部公开数据整理） | 高 |
| CG-02 | 区域层级：省级 level=1、市级（含直辖市辖区）level=2；区域表结构复用 dim_region，parent_id 表达隶属关系 | 高 |
| CG-03 | 区域数据以 SQL 种子文件提供（可重复执行、幂等导入）；前端区域选择改为**省-市级联**下拉 | 高 |
| CG-04 | 行政区划数据仅内置导入，不提供前端随意增删（管理员可查看完整列表） | 中 |

### 2.2 省级参数管理

| 编号 | 需求 | 优先级 |
|---|---|---|
| CG-05 | 每省维护一组特征参数：GDP（亿元）、第二产业占 GDP 比重（%）、煤炭占能源消费比重（%）、单位 GDP 能耗（吨标煤/万元）、所属电网区域、是否供暖省份、GDP 年均增速 | 高 |
| CG-06 | 参数值基于国家统计局/能源统计年鉴**公开数据整理**（演示口径，页面标注"公开统计近似值"） | 高 |
| CG-07 | 管理员可查看与调整省级参数（调整后重新生成生效）；参数表设计独立于区域表，便于扩展 | 中 |

### 2.3 数据生成

| 编号 | 需求 | 优先级 |
|---|---|---|
| CG-08 | **全量模式**：一次性生成 2021-01 至"已过完的最新月份"的全部月度数据（当前约 6 年，约 48 万条）；生成前清空旧模拟数据 | 高 |
| CG-09 | **增量模式**：仅生成"已过完的最新月份"一个月的数据（约 8000 条）；执行后自动触发该月核算 | 高 |
| CG-10 | **幂等保障**：同一 (区域, 行业, 能源, 年, 月) 不重复插入（数据库唯一键 + 生成前校验），重复执行不产生重复数据 | 高 |
| CG-11 | **月度自动执行**：定时任务每月 1 日 00:30 执行增量模式；执行结果与失败原因记录日志，失败可手动补跑 | 高 |
| CG-12 | 生成结果返回摘要：条数、区域数、省份汇总 top/bottom、全国总量、耗时；生成耗时目标：全量 ≤ 5 分钟、增量 ≤ 30 秒 | 中 |
| CG-13 | 保留异常值注入能力（供预警模块 AI 检测演示），注入比例可配置，默认 0.4% | 中 |

### 2.4 各省特点建模

| 编号 | 需求 | 优先级 |
|---|---|---|
| CG-14 | 活动数据 = 市 GDP × 行业能源强度 × **省级系数**（产业结构、煤炭占比、能耗强度）× 季节因子 × 年增长 × 随机波动；沿用主 SRS 的强度矩阵框架，省级系数实现省际差异 | 高 |
| CG-15 | **供暖季节因子**：供暖省份 11~3 月热力与煤炭消费显著抬升（冬季峰形），非供暖省份维持现有季节曲线 | 高 |
| CG-16 | **电网区域因子**：电力排放核算按省份所属电网区域取对应因子（六大区域因子表），替代原单一全国因子 | 高 |
| CG-17 | **常识校验**：生成后自动校验——全国年总量落在 100~130 亿吨；广东/江苏居排放前列；西藏居末；山西煤炭占比最高；不满足时生成结果附校验报告提示 | 中 |

### 2.5 旧数据切换

| 编号 | 需求 | 优先级 |
|---|---|---|
| CG-18 | 全国模式初始化（全量生成）时，删除原"演示省"全部数据：区域（level 1/2/3 旧行）、活动数据、核算结果、关联预警记录、已存情景 | 高 |
| CG-19 | 切换为一次性动作，由管理员确认后执行；提供旧数据备份 SQL 导出能力（导出为脚本文件） | 中 |

### 2.6 全国地图大屏

| 编号 | 需求 | 优先级 |
|---|---|---|
| CG-20 | 大屏页升级为**全国地图热力**：省级着色（按最新年排放量分级设色）、悬停显示省名与总量、下钻（点击省 → 该省数据面板） | 高 |
| CG-21 | 地图数据本地化存储（GeoJSON 内置，无外网依赖），注明数据来源 | 高 |
| CG-22 | 大屏保留既有 KPI/趋势/结构图表，形成"地图 + 指标"综合大屏 | 中 |

## 3 数据需求

### 3.1 区域表（dim_region 复用）

| 字段 | 说明 |
|---|---|
| region_code | GB/T 2260 行政区划代码（省 2 位、市 4 位、直辖市辖区 6 位） |
| region_name | 真实名称（如"江苏省""南京市"） |
| parent_id / level | 省 0/1；市 省id/2 |
| gdp | 市 GDP（亿元，公开统计近似值） |

### 3.2 省级参数表（新增 province_param）

| 字段 | 类型 | 说明 |
|---|---|---|
| region_id | int | 省级区域ID（唯一） |
| gdp | decimal | 省 GDP（亿元） |
| secondary_ratio | decimal | 第二产业占 GDP 比重（%） |
| coal_ratio | decimal | 煤炭占能源消费比重（%） |
| energy_intensity | decimal | 单位 GDP 能耗（吨标煤/万元） |
| grid_code | varchar(10) | 电网区域：HB/DB/HD/HZ/XB/NF |
| heating | tinyint | 1=供暖省份 0=否 |
| gdp_growth | varchar | GDP 年均增速序列（JSON 数组，按年份） |

### 3.3 电网区域因子（factor_emission 扩展）

| 区域 | 编码 | 电力因子（kgCO₂/kWh，公开公告口径） |
|---|---|---|
| 华北 | HB | 0.9810 |
| 东北 | DB | 1.0603 |
| 华东 | HD | 0.7496 |
| 华中 | HZ | 0.6231 |
| 西北 | XB | 0.7094 |
| 南方 | NF | 0.5217 |

> 实现时以生态环境部最新年度公告为准，页面标注来源年份。

### 3.4 数据规模（实测推算）

- 市级区域 ~410 个（含直辖市辖区）× 24 行业能源组合 × 12 月 × 6 年 ≈ **71 万条**活动数据
- 月度核算表同量级；年度核算表 ~5.9 万行

## 4 接口需求

| 接口 | 说明 |
|---|---|
| `POST /data/generate` | 扩展 mode 参数：all（全量）/ recent（最近一月增量）；返回生成摘要与校验报告 |
| `GET /data/status` | 扩展返回：区域数（省/市）、年份范围、全国总量 |
| `GET /data/region/tree` | 省-市级联数据（前端下拉用） |
| `GET /param/province/list`、`PUT /param/province/{id}` | 省级参数查看/调整（管理员） |
| `GET /analysis/map` | 全国地图热力数据：各省最新年排放（地图大屏数据源） |
| `GET /analysis/province/{id}` | 点击省份下钻：该省 KPI/趋势/结构 |

## 5 非功能需求

| 编号 | 需求 |
|---|---|
| NFR-CG-01 | 全量生成 ≤ 5 分钟（71 万条批量写入）；增量 ≤ 30 秒 |
| NFR-CG-02 | 幂等：同月重复执行不产生重复数据（唯一键兜底） |
| NFR-CG-03 | 定时任务失败不影响平台其他功能；失败状态可查询、可手动补跑 |
| NFR-CG-04 | 地图大屏离线可用（GeoJSON 本地化），首屏加载 ≤ 3 秒 |
| NFR-CG-05 | 所有公开统计数据页面标注"演示口径，公开统计近似值" |

## 6 验收标准

| 编号 | 验收场景 | 要点 |
|---|---|---|
| AT-CG-01 | 行政区划导入 | 区域数与民政部口径一致；抽查江苏(32)/南京(3201)/北京(11)/海淀(110108)编码正确 |
| AT-CG-02 | 全量生成 | 6 年内每月数据完整；重复执行不产生重复行；耗时 ≤ 5 分钟 |
| AT-CG-03 | 总量校验 | 最新完整年（2025）全国总量在 100~130 亿吨；校验报告自动生成 |
| AT-CG-04 | 省际常识 | 广东/江苏/山东居前列；西藏居末；山西煤炭占比最高 |
| AT-CG-05 | 增量自动 | 手动触发增量生成上月数据并自动核算；模拟下月定时任务逻辑验证幂等 |
| AT-CG-06 | 旧数据切换 | 切换后旧"演示省"区域与关联数据全部清除 |
| AT-CG-07 | 地图大屏 | 断网环境地图正常渲染；省着色分级正确；点击省可下钻 |
| AT-CG-08 | 供暖差异 | 黑龙江 1 月热力相关排放显著高于 7 月；广东无此特征 |
