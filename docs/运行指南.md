# 绿碳智衡 · 运行指南

本文档说明平台的完整启动流程（数据库 → Python 算法服务 → 后端 → 前端）。

---

## 一、环境要求

| 软件 | 版本 | 说明 |
|---|---|---|
| JDK | 17+（本机 23 亦可） | 后端编译运行 |
| MySQL | 8.0+ | 数据库 |
| Python | 3.9+ | 算法服务 |
| Node.js | 18+ | 前端构建 |

---

## 二、数据库初始化（仅首次或重置时）

按顺序执行 `docs/sql/` 下三个文件（均幂等，可重复执行）：

```bash
mysql -uroot -p < docs/sql/init.sql           # 1. 建库建表 + 基础字典/因子/账号
mysql -uroot -p < docs/sql/migration_cn.sql   # 2. 结构迁移（省级参数表/电网因子/唯一键）
mysql -uroot -p < docs/sql/regions_cn.sql     # 3. 全国行政区划 + 省级参数 + 电网因子数据
```

初始化账号：`admin / admin123`（管理员）、`demo / admin123`（业务用户）。

## 三、Python 算法服务启动（预测/仿真/异常检测/RAG 问答）

### 3.1 首次安装依赖

```powershell
cd d:\develop\project\smart\algo
pip install -r requirements.txt
```

> 依赖含 torch（约 200MB+），下载较慢属正常。**未装 torch 也不影响运行**——预测会自动降级为趋势模型。

### 3.2 配置 DeepSeek API Key（可选但建议）

方式一：系统环境变量（在设置之后**新开的终端**才会继承）

```powershell
setx DEEPSEEK_API_KEY "sk-你的Key" /M
```

方式二（推荐，最省心）：在 `algo` 目录下复制 `.env.example` 为 `.env` 并填入 Key

```
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxx
```

### 3.3 启动服务

```powershell
cd d:\develop\project\smart\algo
python -m uvicorn main:app --host 0.0.0.0 --port 8000
```

### 3.4 验证

浏览器打开 http://localhost:8000/health ，返回：

```json
{"code":200,"msg":"ok","service":"algo","api_key_configured":true}
```

`api_key_configured` 为 `true` 即 AI 问答/报告可用；为 `false` 时 AI 功能走离线兜底（哈希检索 + 预设话术），其余功能不受影响。

### 3.5 常见问题

| 现象 | 处理 |
|---|---|
| `getaddrinfo failed` | 网络/DNS 抖动，检查联网后**重启服务**（模型下载线程不会自动重试） |
| 首次问答较慢（约 15 秒） | BGE 向量模型（约 100MB）后台下载中，走国内镜像；下载完自动升级语义检索 |
| 上传新文档后问答搜不到 | 上传/停用/删除会主动刷新缓存；最迟 30 秒 TTL 后自动生效 |
| 改了 main.py 不生效 | 必须重启 uvicorn（Ctrl+C 后重新执行启动命令） |

## 四、后端启动

```powershell
cd d:\develop\project\smart\smart
.\mvnw.cmd spring-boot:run
```

- 启动后：http://localhost:8080/doc.html 为接口文档
- 数据库密码等配置在 `src/main/resources/application.yml`
- 首次启动后建议在工作台执行「生成模拟数据」（全量约 5 分钟）+「执行核算」（约 2 分钟），或调用接口：
  - `POST /data/generate {"mode":"all","startYear":2021}`（管理员）
  - `POST /calc/execute {"startYear":0,"endYear":0}`
- 此后数据**每月 1 日 00:30 自动增量生成上月数据并核算**，无需人工干预

---

## 五、前端启动

```powershell
cd d:\develop\project\smart\web
npm install        # 仅首次
npm run dev        # 开发模式 http://localhost:5173
```

或构建部署：

```powershell
npm run build      # 产物在 dist/，交由 Nginx 托管（/api 反向代理到 8080）
```
