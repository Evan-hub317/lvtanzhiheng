# 绿碳智衡 · 运行指南

本文档说明平台的完整启动流程（数据库 → Python 算法服务 → 后端 → 前端）。

---

## 一、环境要求

| 软件 | 版本 | 说明 |
|---|---|---|
| JDK | 17+（本机 23 亦可） | 后端编译运行 |
| MySQL | 8.0+ | 数据库 |
| Python | 3.9+ | 算法服务 |
| Node.js | 18+ | 前端构建 |

## 二、数据库初始化（仅首次或重置时）

数据库初始化分两步（均幂等，可重复执行）：

```bash
mysql -uroot -p < docs/sql/smart_carbon_struct.sql   # 1. 表结构（仓库内，28 张表）
mysql -uroot -p < smart_carbon.sql                  # 2. 结构与数据完整版（含基础字典/因子/账号/预设情景/行政区划/2016 年至今全部模拟数据与核算结果）
```

## 三、Python 算法服务启动（预测/仿真/异常检测/RAG 问答）

### 3.1 首次安装依赖

```powershell
cd d:\develop\project\smart\algo
pip install -r requirements.txt
```

> 依赖含 torch（约 200MB+），下载较慢属正常。**未装 torch 也不影响运行**——预测会自动降级为趋势模型。

### 3.2 配置大模型与数据库（配置文件 algo/.env）

编辑 `algo/.env`（该文件为配置文件，优先于系统环境变量）：

```ini
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxx
DEEPSEEK_MODEL=deepseek-flash
# 备用模型（故障转移）：DeepSeek 不可用时自动切换千问
BACKUP_API_KEY=sk-xxxxxxxxxxxxxxxx
BACKUP_BASE_URL=https://ws-7ye0l4xplondv1u2.cn-beijing.maas.aliyuncs.com/compatible-mode/v1
BACKUP_MODEL=qwen3.8-flash
MYSQL_HOST=127.0.0.1
MYSQL_PORT=3306
MYSQL_USER=root
MYSQL_PASSWORD=root
MYSQL_DB=smart_carbon
```

> Key 不填也能启动：AI 问答走离线兜底、报告接口返回 400，其余功能不受影响。

### 3.3 启动服务

```powershell
cd d:\develop\project\smart\algo
python -m uvicorn main:app --host 0.0.0.0 --port 8000
```

### 3.4 验证

浏览器打开 http://localhost:8000/health ，返回：

```json
{"code":200,"msg":"ok","service":"algo","api_key_configured":true}
```

`api_key_configured` 为 `true` 即 AI 问答/报告可用；为 `false` 时 AI 功能走离线兜底（哈希检索 + 预设话术），其余功能不受影响。

### 3.5 常见问题

| 现象 | 处理 |
|---|---|
| `getaddrinfo failed` | 网络/DNS 抖动，检查联网后**重启服务**（模型下载线程不会自动重试） |
| 首次问答较慢（约 15 秒） | BGE 向量模型（约 100MB）后台下载中，走国内镜像；下载完自动升级语义检索 |
| 上传新文档后问答搜不到 | 上传/停用/删除会主动刷新缓存；最迟 30 秒 TTL 后自动生效 |
| 改了 main.py 不生效 | 必须重启 uvicorn（Ctrl+C 后重新执行启动命令） |

## 四、后端启动

```powershell
# 必须回到项目根目录执行（upload-dir 按进程工作目录解析，上传文件落项目根 uploads/）
cd d:\develop\project\smart
mvn -f smart/pom.xml spring-boot:run
```

- 启动后：http://localhost:8080/doc.html 为接口文档
- 数据库密码等配置在 `src/main/resources/application.yml`
- 上传文件目录：项目根 `uploads/`（知识库 `kb/`、头像 `images/` 同级）
- 模拟数据由内置数据生成算法产出，随完整版 SQL 一并导入（见第二章），启动后即可直接查看
- 系统内置定时任务**每月 1 日 00:30 自动增量更新上月数据并核算**

---

## 五、前端启动

```powershell
cd d:\develop\project\smart\web
npm install        # 仅首次
npm run dev        # 开发模式 http://localhost:5173
```

或构建部署：

```powershell
npm run build      # 产物在 dist/，交由 Nginx 托管（/api 反向代理到 8080）
```
